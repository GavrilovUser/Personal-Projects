## Консольный банк
Консольное приложение, написанное на Java.
Нету дб, и много чего ещё. Зато работает

### Запуск
для запуска приложения, достаточно написать следующее в корне проекта:
~~~Bash
./gradlew run
~~~
корень проекта это то, где находятся:  
`src/`  
`build.gradle.kts`  
`settings.gradle.kts`  
и другие
