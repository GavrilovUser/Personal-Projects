## Бэкенд кликер
Написан на Spring Boot / Rest API

### Запуск
**В корне проекта нужно ввести:**
~~~Bash
sh gradlew bootRun
~~~

### Использование
**Запросы отправлять по адресу:**
~~~Path
http://127.0.0.1:8080/
~~~

**Отправлять можно следующее:**  
- `[POST] /accounts` – Создание нового аккаунта
- `[POST] /accounts/{id}` – Добавление единицы к балансу определённого аккаунта
- `[GET] /accounts/{id}` – Получение данных определенного аккаунта
