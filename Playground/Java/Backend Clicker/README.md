## Бэкенд кликер
Написан на Spring Boot / Rest API

### Использование
Для запуска сервера нужно зайти в корень проекта, и ввести:
~~~Bash
./gradlew bootRun
~~~
Или
~~~Bash
sh gradlew bootRun
~~~

**После запуска сервера, можно вводить запросы:**
~~~Prompt
http://localhost:8080/api/balance
~~~
или
~~~Prompt
http://127.0.0.1:8080/api/balance
~~~
