## Система аккаунтов
Присутствует возможность управлять аккаунтами  
- `backend` на Java & Spring Boot  
- `frontend` на Python & Aiogram 3

### Запуск
Докера нет, потому-что сделано на телефоне _без_ Рут-Прав, а другие контейнеры не хотелось использовать

**Запуск backend**  
1. Сперва нужно перейти в директорию `Account/backend`
2. Потом нужно ввести следующее:
~~~Bash
./gradlew bootRun
~~~
Если выдало ошибку `Permisson Denied`, пробуй:
~~~Bash
sh gradlew bootRun
~~~
3. После этих действий сервер должен запуститься

**Запуск frontend**  
Перед началом нужно перейти в директорию `Account/frontend`  
затем ввести следующую команду:
~~~Bash
cp .env.example .env
~~~
После этого замени значения секретов в `.env` на свои

1. По пути `Account/frontend` выполни следующую команду:
~~~Bash
python -m venv .venv
~~~
2. Затем выполни команду:
~~~Bash
source .venv/bin/activate
~~~
3. Затем выполни команду:
~~~Bash
pip install -r requirements.txt
~~~
4. С настройкой закончено, осталось выполнить команду для запуска бота:
~~~Bash
python app.py
~~~

### Использование
**Команды бота**
- `/start` – Показывает главное меню

**Запросы на бэкенд**
- `[GET] /users` – Получить список всех аккаунтов
- `[POST] /users {"name": "имя"}` – Создать новый аккаунт
- `[GET] /users/{id}` – Получить данные определённого аккаунта
